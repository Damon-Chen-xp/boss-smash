# 暴打老板 · 摸鱼发泄室

一个给上班族泄愤用的小游戏：**捏一个你最想打的人 → 暴打 → 用吐槽给武器附魔 → 一路打到老板**。
纯 Canvas 手绘，零图片资源、零依赖，网页版和微信小游戏共用同一套核心代码。

---

## 二、怎么玩

| 操作 | 效果 |
|---|---|
| 点 / 按住 BOSS | 连续殴打，按住不放会自动连击 |
| 滑动 | 划一下算一次命中，刷连击更快 |
| 连击 | 每下 +2% 伤害，2.6 秒不打就断 |
| 金币 | 打中掉落，武器库里换更狠的家伙 / 升级武器 |
| 怒气条 | 满了点「必杀」，一次打出 20 倍伤害 |
| 💬 吐槽强化 | **输入一句话，越另类武器越强**（核心玩法，见下） |

## 三、吐槽强化（核心玩法）

点战斗界面的「💬 吐槽强化」输入一句话，本地算法会打出「另类度」评分（0–100）并给出逐条反馈：

**加分项**：比喻手法 +14、跨界联想（职场 × 量子物理 这种）+16/领域、稀有词库（合并单元格 / 熵值 / 薛定谔…）+15、高级词汇 +8、灵魂反问 +12、连珠炮排比 +10、数据佐证 +8、中英混搭 +7、表情包 +6、押韵 +9

**扣分项**：老梗警告（996 / 内卷 / 福报 / 画饼…-9/个）、重复说过的话 -30、太短 -22

**转化**：评级 `D→SSS` 对应武器倍率 `1.0× ~ 3.0×`，持续 18–35 秒；`SS` 以上额外加暴击率，`SSS` 还能无视 BOSS 闪避。评分明细会一条条列出来，玩家能明确知道「下一句该怎么写」。

> 敏感词会自动打码，不影响得分。整套算法在 `src/lib-roast.js`，词库可自行扩充。

## 四、其他内容

- **捏脸搭积木**：脸型 / 肤色 / 发型 / 眉毛 / 眼睛 / 嘴巴 / 眼部 / 服装 / 道具 / 场景，共 12 类 70+ 种部件（含鼻子、胡须），可随机、可改名和口头禅；捏脸页轮播预览 8 种表情。
- **武器**：拖鞋 → 机械键盘 → 保温杯 → 打印机 → 滚烫美式 → 离职信 → 仲裁申请书（伤害 ×1 ~ ×15，可逐级升级）。
- **关卡**：实习生 / 画饼侠 / 周报狂魔 / 需求变更兽 / 会议终结者 / 甲方 / HR / 终极画饼王，8 关一轮回，越往后越肉、闪避越高，第 4 关起 BOSS 会「画饼回血」。
- **表情与打击反馈**：BOSS 表情随血量递进（得意→恼怒→求饶→崩溃→躺平），受击瞬间切痛苦/震惊脸并挤压变形；头发越打越乱，脸上累积淤青/肿包/创可贴/血口子，重伤流鼻血、濒死画面泛红；配合震屏、冲击波、暴击大数字与手机振动。

## 五、音效系统

音效是**运行时用 JS 合成 PCM → 编码成 WAV → 交给 HTML5 `<audio>` 播放**，不需要任何音频文件、不发任何网络请求（`src/lib-audio.js`）。

> 为什么不用 WebAudio：微信内置浏览器（X5 内核）对 WebAudio 支持不稳定，且 **iOS 侧边静音键会直接掐掉 WebAudio**，而 HTML5 `<audio>` 走媒体音量不受影响。所以网页端默认走 HTML5 `<audio>`，微信小游戏端才用 `wx.createWebAudioContext()` 播同一份合成结果。

| 音效 | 合成方式 |
|---|---|
| 普通打击 | 低频闷响（195→46Hz）+ 肉体噪声 + 巴掌高频脆响；**连击越高音调越脆**，高连击额外叠金属泛音 |
| 暴击 | 低频撞击 + 4 个不谐和金属泛音（880/1290/1760/2350Hz）+ 上滑 ping + 金币声 |
| 金币 | 双音叮当（B5→E6） |
| 必杀 | 75Hz 轰鸣下扫 + 锯齿扫频 + 四音和弦上扬 |
| 过关 | 大调五音上行琶音 |
| 吐槽评分 | SSS 六音上行 + 高频闪光；C/D 是下行「哇哦」 |
| 其他 | 未命中、购买升级、按钮、BOSS 挑衅 |

- 打击音按连击预制 6 档音高，每次播放还有 ±6% 随机变速，**不会听起来像复读机**。
- 右上角喇叭图标可一键开关，状态存在存档里。
- 解锁策略：首次触摸 / 点击 / `WeixinJSBridgeReady` 都会尝试解锁（前 5 次），适配各家内核的自动播放限制。
- 微信小游戏端走 `wx.createWebAudioContext()`（基础库 2.19+），过低则自动静音，不会报错。

## 六、运行

**网页版**：直接双击 `index.html`。

**微信小游戏**：
1. 打开微信开发者工具 → 导入项目 → 选择 `boss-smash-wxgame` 目录
2. 填写你的小游戏 AppID（或选「测试号」）
3. 核心代码在 `boss-smash-wxgame/src/`，改完同步更新网页版的 `src/` 保持一致

## 七、可调参数

都在 `src/game-core.js` 顶部：
- `WEAPONS`：武器名 / 伤害倍率 / 价格
- `BOSSES`：BOSS 名字、口头禅、特性
- `bossOf()` 里的 `460 * Math.pow(1.72, lv-1)`：关卡血量曲线
- `SAMPLES` / `src/lib-roast.js` 里的 `DOMAINS`、`RARE`、`CLICHE`：吐槽评分词库
